# Dulce Cuchara

## Descripción
Catálogo web de postres cuchareables que permite
consultar productos y realizar pedidos por WhatsApp.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Estructura
- pages: páginas secundarias.
- css: hojas de estilos.
- js: funcionalidades.
- assets: imágenes e iconos.

## Funcionalidades
- Catálogo de postres.
- Filtros por categorías.
- Detalles de productos.
- Carrito de compras.
- Pedidos por WhatsApp.
- Panel administrativo.

## Proyecto académico
Desarrollo de Software en Equipo - TSPi.
